# Manuscript sources

`main.pdf` is the nine-page Elsevier CAS single-column draft. Highlights are separate in `highlights.txt`. `main.tex`, `sections/`, `references.bib` and `figures/` are the authors' sources.

To compile, obtain the official [Elsevier CAS bundle](https://ctan.org/pkg/els-cas-templates) (`cas-sc.cls`, `cas-common.sty` and the standard `thumbnails/cas-email.jpeg`) and the [elsarticle bibliography styles](https://ctan.org/pkg/elsarticle) (`elsarticle-num-names.bst`). These third-party template files retain LPPL licensing and are not relicensed or vendored here. Compile with pdfLaTeX, BibTeX and two further pdfLaTeX passes.

The default author/submission footer wording is disabled while page counters remain. The CAS no-logo flag replaces the email icon with text-only contact details. Template dependencies themselves are unmodified. The article-info keywords are selected index terms, not an exhaustive vocabulary list. The abstract and introduction explicitly name class imbalance and modality imbalance.

This draft is unpublished research. Author contribution statements and submission details require the authors' verification. Manuscript copyright remains with its authors; the repository code license does not relicense the paper or cited works.
