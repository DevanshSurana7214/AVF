# Reference audit

All fifteen references are cited and numbered in the manuscript. Ten DOI-bearing papers were checked against publisher-registered Crossref metadata; records are in `REFERENCE_REGISTRY_AUDIT.json`. Official NeurIPS BibTeX records were retrieved separately. ICLR and JMLR entries were checked against the conference/author records and JMLR article record. OpenReview's web page presented a browser challenge during recheck; no inaccessible record was represented as newly read.

Confirmed additions: TIMM pages 1–8, Flex-MoE pages 98782–98805, tabular benchmark pages 507–520. The class-balanced-loss citation now uses the IEEE DOI version, pages 9260–9269. The CVF-hosted proceedings use different pagination (9268–9277); the versions were not silently mixed. Existing corrected Sagawa and ADNI-review author lists were reconfirmed. LightGBM's official BibTeX leaves pages empty, so no page range was invented. ICLR papers do not require an invented page range.

Foundational and recent papers are chosen for specific roles: ADNI resource, regional multimodal diagnosis, multimodal taxonomy, incomplete-modality methods, class imbalance, logit adjustment, group robustness, shortcut learning, tree baselines and model-selection bias. Citation does not imply original-method reproduction or erase the current study's evaluation limitations.
